# Status katalog

Semua 18 entri merupakan **angka ilustratif untuk pengujian perangkat lunak**,
bukan hasil pengukuran menu kantin dan bukan dataset gizi terverifikasi.
Ukuran pada kategori hanya asumsi contoh porsi. Jangan menyatakan angka ini
sebagai kandungan pasti suatu merek, warung, atau makanan.

Sebelum dipakai untuk pencatatan nyata, tim wajib mengganti nilainya dengan data
bersumber, menyamakan berat/porsi dan kondisi matang/mentah, serta menyimpan
referensi dan tanggal akses dalam dokumen pendamping ini. Untuk produk kemasan,
gunakan angka dan takaran saji pada label produk yang bersangkutan.

Skema katalog tetap tepat tujuh atribut sesuai kontrak. Nilainya adalah gizi
**per satu porsi contoh**; JSON log menyimpan total yang **sudah dikali porsi**.
Total kalori dari sumber dapat berbeda dari pendekatan 4/4/9 pada diagram makro.

user_data.json awal kosong. Aplikasi hanya memiliki satu profil lokal tanpa
autentikasi. Jangan commit riwayat pribadi ke repositori publik.
